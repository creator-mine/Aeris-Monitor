# Aeris Monitor — обзор проекта

> **Коротко:** это домашняя система, которая измеряет температуру, влажность,
> давление, качество воздуха и освещённость. Данные показываются в приложении,
> а история хранится у вас, а не в чужом облаке.

---

## Вступление

### Что это такое

Aeris Monitor — это небольшая домашняя метеостанция. Она состоит из плат с
датчиками и программы, которая собирает и показывает их показания.

Система умеет:

- измерять параметры воздуха;
- хранить историю измерений;
- показывать текущие значения и графики;
- обновляться без проводов;
- присылать уведомления;
- выполнять простые правила: «слишком жарко — сообщи».

Всё работает на вашем оборудовании. Платной подписки нет.

### Зачем это нужно

Обычные «умные» датчики отправляют данные в облако производителя. Из-за этого:

- без интернета система часто не работает;
- нужна регистрация и подписка;
- непонятно, кто видит ваши данные;
- новый датчик трудно добавить.

Здесь всё иначе: данные хранятся у вас, система работает без чужого облака, а
новые датчики подключаются сами.

### Кому подходит

- дом и квартира;
- дача и теплица;
- офис или кабинет;
- учебные проекты;
- разработчики, которым интересен открытый код.

### Главные принципы

- **Данные принадлежат вам.**
- **Работа без облака.**
- **Новые датчики подключаются без перепрошивки.**
- **Открытый код.**
- **Безопасность по умолчанию.**

## Первая глава. Как устроено устройство

### Из чего состоит

```
Датчики → сенсорный модуль → главный контроллер → карта памяти
                                             └→ Wi-Fi → приложение и сервер
```

- **Датчики** измеряют температуру, свет, давление и другие величины.
- **Сенсорный модуль** собирает показания и передаёт их дальше.
- **Главный контроллер** хранит историю, отправляет данные и принимает команды.
- **Карта памяти** хранит историю, если интернет пропал.
- **Приложение и сервер** показывают данные и помогают управлять системой.

### Какие датчики поддерживаются

| Датчик | Что измеряет |
|---|---|
| **BME680** | температуру, влажность, давление, качество воздуха |
| **BH1750** | освещённость |
| **BMP280** | температуру и давление |
| **SCD30** | углекислый газ, температуру, влажность |
| **INA219** | напряжение, ток, мощность |

Новый датчик можно добавить, не меняя приложение и сервер.

### Как идёт измерение

1. Датчик измеряет величину.
2. Сенсорный модуль передаёт значение контроллеру.
3. Контроллер сохраняет его на карту памяти.
4. Свежее значение уходит в приложение.
5. Приложение может показать график за день, неделю или месяц.

Если интернет пропал, измерения и запись продолжаются. Данные не теряются.

### Что умеет устройство

- **Настраиваться с телефона.** При первом включении плата создаёт Wi-Fi сеть
  `Aeris-Setup-XXXX`. Через неё вводятся данные домашней сети и доступы.
- **Хранить историю.** На карте памяти, с контролем свободного места.
- **Обновляться по воздуху.** Новая версия скачивается, проверяется и
  устанавливается.
- **Откатываться при ошибке.** Если новая версия не запустилась, возвращается
  старая.
- **Перезагружаться при зависании.** За этим следит watchdog.
- **Управлять реле.** На ESP32-C3 есть один выход для реле.
- **Показывать диагностику.** Логи, состояние памяти и Wi-Fi.

### Как проходят обновления

1. Устройство проверяет новую версию.
2. Скачивает файл по защищённому соединению.
3. Проверяет целостность.
4. Устанавливает и перезагружается.
5. Если что-то пошло не так — возвращается рабочая версия.

Пароли и токены не хранятся в публичном файле обновления. Они лежат в защищённой
памяти самого устройства.

### Надёжность

- история пишется на карту памяти;
- система работает без интернета;
- старые файлы удаляются, когда место заканчивается;
- при зависании устройство перезагружается само;
- неудачное обновление можно откатить.

## Вторая глава. Приложение, сервер и сайт

### Приложение

Приложение работает на Android, в браузере и на компьютере.

| Раздел | Что можно делать |
|---|---|
| **Главная** | Смотреть устройства и текущие показания |
| **Графики** | Строить графики за разные периоды |
| **Устройства** | Добавлять и переименовывать устройства |
| **Настройка** | Настраивать конкретное устройство |
| **Прошивка** | Обновлять устройство по воздуху |
| **Настройки** | Указывать адрес сервера, токен и тему |
| **Умный дом** | Создавать правила и уведомления |
| **Логи** | Смотреть диагностику |

### Уведомления

На Android приложение может работать в фоне. Когда срабатывает правило,
появляется системное уведомление. Для этого приложение держит соединение с
сервером, даже если окно закрыто.

### Сервер

Сервер — это помощник. Он:

- хранит список устройств;
- следит, на связи ли они;
- отдаёт историю;
- выполняет правила умного дома;
- показывает панель администратора.

Сервер можно поставить на недорогой VPS или домашний компьютер.

### Сайт

Сайт — это витрина проекта. На нём есть:

- главная страница с описанием;
- вики с инструкциями;
- веб-версия приложения;
- панель администратора;
- файлы обновлений для устройств.

### Как всё запущено

Сервер, брокер сообщений и сайт работают в Docker. Снаружи их закрывает nginx:
он принимает запросы, включает защищённое соединение и направляет трафик внутрь.

На одном сервере можно держать несколько сайтов. Каждый сайт получает своё имя и
свой сертификат.

### Безопасность

- сайт и обновления работают по HTTPS;
- сообщения устройств передаются по защищённому соединению;
- запись и история закрыты паролем или токеном;
- секреты не попадают в публичные файлы;
- обновления проверяются по контрольной сумме;
- делаются ежедневные резервные копии.

### Что уже готово

- плата с датчиками и автоматическим подключением новых датчиков;
- история на карте памяти;
- приложение для Android, браузера и компьютера;
- сервер с правилами и панелью;
- сайт с вики и веб-приложением;
- обновления по воздуху;
- фоновые уведомления;
- защищённое соединение;
- управление реле;
- резервные копии.

### Планы

- прямое соединение приложения с устройством;
- работа в разных сетях без настройки;
- обмен сообщениями через сервер по желанию;
- больше каналов для реле;
- проверка на реальных телефонах и устройствах.

## Заключение

### Итог

Aeris Monitor — это законченная домашняя система мониторинга. Она объединяет
датчики, прошивку, приложение, сервер и сайт в один понятный продукт.

Система измеряет параметры среды, хранит историю, показывает данные в реальном
времени, обновляется по воздуху и поддерживает простые правила.

### Почему это важно

- **Независимость.** Система работает без чужого облака.
- **Прозрачность.** Понятно, где лежат данные.
- **Расширяемость.** Новые датчики добавляются легко.
- **Обучение.** Видно весь путь от электроники до сайта.
- **Экономия.** Нет обязательной подписки.
