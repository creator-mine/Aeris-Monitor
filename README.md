## Компоненты системы

### 1. Главный контроллер (`firmware/main_controller/`)
**Платформа:** ESP32-C3 (Lolin C3 Mini) + Arduino Framework

- **Подключение:** WiFi станцией, MQTT-клиент к брокеру
- **Локальные датчики (I2C):** BME680 (температура, влажность, давление, газ) и BH1750 (освещённость)
- **UART-мост:** Принимает данные от удалённых сенсорных модулей по бинарному протоколу (`0xAA 0x55` + CRC-16) и ретранслирует их в MQTT
- **SD-карта:** Локальное логирование показаний в CSV
- **MQTT-топики:**
  - Публикация: `iot/<device_id>/sensors/<type>`, `iot/<device_id>/status`
  - Подписка: `iot/<device_id>/commands` (поддерживаются команды `restart`, `read_sensor`)

### 2. Сенсорный модуль (`firmware/sensor_module/`)
**Платформа:** ESP32-C6 (Lolin C3 Mini) + Arduino Framework

- Автономное устройство с теми же датчиками (BME680 + BH1750)
- Передаёт данные на главный контроллер по UART с использованием бинарного протокола
- Поддерживает команды: `CMD_SENSOR_DATA` (20 байт float), `CMD_HEARTBEAT`, `CMD_READ_SENSOR`, `CMD_CONFIG_UPDATE`
- CRC-16 для контроля целостности пакетов

### 3. Мобильное приложение (`mobile_app/`)
**Технологии:** Flutter, Dart, Provider (state management)

Пять вкладок навигации:

| Вкладка | Функции |
|---------|---------|
| **Главная** | Список устройств, онлайн-статус, сетка показателей датчиков в реальном времени через MQTT |
| **Графики** | Интерактивные временные графики (fl_chart) с выбором диапазона: 1ч, 6ч, 24ч, 7д, 30д + статистика (мин/сред/макс) |
| **Устройства** | CRUD-управление устройствами через REST API |
| **Прошивка** | Сборка (`platformio run`) и загрузка прошивки на ESP32 через COM-порт прямо с телефона, история версий (Hive) |
| **Настройки** | API URL, MQTT-брокер, тёмная тема, цвет акцента, фоновое изображение |

### 4. Серверная часть (REST API)
- **CRUD** для устройств, модулей и оповещений
- **Эндпоинты:** `/api/v1/devices`, `/api/v1/devices/{id}/sensors/{type}/data`, `/api/v1/alerts`, `/api/v1/health`
- Хранение исторических данных с фильтрацией по времени и интервалу агрегации

## Протоколы взаимодействия

### UART (между модулями ESP32)
```
[0xAA][0x55][module_id][cmd][len_hi][len_lo][payload...][crc_hi][crc_lo]
```

- Фиксированный заголовок `0xAA 0x55`
- CRC-16/CCITT для верификации
- Поддерживаемые команды: регистрация, запрос данных, отправка данных, heartbeat, обновление конфигурации

### MQTT (контроллер → приложение)
- **Формат:** JSON
- **Частота:** Каждые 5 секунд (настраивается)
- **Топики:** Иерархическая структура `iot/<device_id>/sensors/<type>`
- **Heartbeat:** Каждые 30 секунд

### REST API (приложение ↔ сервер)
- HTTP-запросы через Dio
- Content-Type: `application/json`
- Таймаут подключения: 10 секунд

## Принцип работы

1. **Сбор данных:** Сенсорный модуль (ESP32-C6) и главный контроллер (ESP32-C3) независимо читают показания с датчиков BME680 и BH1750 каждые 5 секунд
2. **Передача на контроллер:** Сенсорный модуль упаковывает данные в бинарный пакет (5 значений float по 4 байта = 20 байт полезной нагрузки) и отправляет по UART с CRC-16
3. **Публикация в MQTT:** Главный контроллер принимает данные от модуля и публикует их вместе с собственными показаниями в MQTT-брокер
4. **Локальное хранение:** Параллельно данные пишутся на SD-карту в CSV-файл
5. **Доставка до приложения:** Мобильное приложение подписано на MQTT-топики через `mqtt_client` и получает данные в реальном времени
6. **Визуализация:** Данные отображаются на дашборде (текущие показания) и на странице графиков (исторические данные за период)
7. **Исторические данные:** Для построения графиков за длительный период мобильное приложение обращается к REST API сервера
8. **Обновление прошивки:** Вкладка "Прошивка" позволяет выбрать проект PlatformIO, собрать его и загрузить на устройство через последовательный порт

## Поток данных (end-to-end)

```
Sensor Module (ESP32-C6)
    │
    ├── BME680: температура, влажность, давление, газ
    ├── BH1750: освещённость
    │
    ├── Каждые 5 секунд → упаковка в бинарный пакет → UART
    │
    ▼
Main Controller (ESP32-C3)
    │
    ├── Собственные датчики (BME680 + BH1750) ← I2C
    ├── Приём данных от модуля ← UART
    │
    ├── Публикация в MQTT ← WiFi
    ├── Логирование на SD-карту
    │
    ▼
MQTT Broker (mosquitto)
    │
    ├── Real-time push
    ▼
Mobile App (Flutter) ← MQTT + REST API
    │
    ├── Dashboard live-показания
    ├── Графики за период (REST)
    ├── Управление устройствами (REST)
    └── Прошивка (PlatformIO CLI)
```

## Зависимости

### Firmware (PlatformIO)
- `knolleary/PubSubClient` — MQTT
- `adafruit/Adafruit BME680 Library` — датчик BME680
- `claws/BH1750` — датчик освещённости
- `adafruit/Adafruit Unified Sensor`
- `bblanchon/ArduinoJson`

### Mobile App (Flutter/Dart)
- `provider` — состояние
- `dio` — HTTP-клиент
- `mqtt_client` — MQTT
- `fl_chart` — графики
- `hive` / `hive_flutter` — локальное хранилище
- `shared_preferences` — настройки
- `google_fonts` — типографика
- `flutter_staggered_animations` — анимации
- `file_picker` — выбор файлов прошивки
