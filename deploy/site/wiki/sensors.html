Реестр драйверов

Драйверы лежат в общей папке и используются обеими прошивками.

firmware/shared/sensor_modules/
├── include/
│   ├── sensor_module.h      базовый интерфейс драйвера
│   ├── sensor_registry.h    реестр: сканирование, опрос, восстановление
│   ├── uart_frame.h         сборка и разбор кадров
│   ├── bme680_module.h
│   ├── bh1750_module.h
│   ├── bmp280_module.h
│   ├── ina219_module.h
│   └── scd30_module.h
└── src/
    ├── sensor_registry.cpp
    ├── bme680_module.cpp
    ├── bh1750_module.cpp
    ├── bmp280_module.cpp
    ├── ina219_module.cpp
    └── scd30_module.cpp

Каждый драйвер сам регистрирует себя одной макросом в конце файла.

Определение по chip ID

Для датчиков с общим диапазоном адресов проверяется регистр идентификатора.

Датчик Регистр Ожидаемое значение Смысл
BME680 0xD0 0x60 Чип точно BME680
BMP280 0xD0 0x58 Чип точно BMP280
BH1750 только отклик по адресу — Диапазон адресов не пересекается
INA219 только отклик по адресу — Единственный адрес — 0x40
SCD30 только отклик по адресу — Фиксированный адрес 0x61

Без такой проверки два чипа на одном адресе определяются как один.

Метрики и единицы

Каждый драйвер возвращает описание метрик и значения в том же порядке.

  • Ключ метрики — короткая строка латиницей.
  • Единица измерения приходит от драйвера.
  • Порядок метрик обязан быть стабильным.
  • Одинаковые ключи у разных датчиков получают префикс.
🚫

Значения NAN и INF в публикацию не попадают.

Отказоустойчивость драйверов

Что произошло Поведение системы
Часть метрик не прочиталась На их место подставляется NAN
Датчик перестал отвечать Запись переводится в офлайн
Датчик ответил снова Создаётся новый клон драйвера
Появился датчик того же типа на новом адресе Создаётся второй независимый экземпляр
Драйвер вернул неверное число метрик Данные выравниваются по описанию

Как добавить свой датчик

Процедура одинакова для любого I²C-датчика.

Заведите два файла в общей папке

Класс наследуется от SensorModule.

Выберите свободный type_id

Возьмите 6.

Опишите адреса и определение

Метод detect() должен подтвердить чип.

Реализуйте init(), read() и metrics()

Порядок значений должен совпадать с metrics().

Отдайте clone() и интервал

clone() возвращает свежий экземпляр.

Зарегистрируйте драйвер макросом

Одна строка в конце файла.

Подключите библиотеку и пересоберите

Добавьте библиотеку в lib_deps и пересоберите.

Минимальный драйвер

#include "sensor_module.h"

class MySensorModule : public SensorModule {
public:
    uint8_t typeId() const override { return 6; }
    const char* moduleName() const override { return "MySensor"; }

    std::vector<uint8_t> i2cAddresses() const override { return {0x48}; }

    bool detect(uint8_t address) override {
        uint8_t chipId = 0;
        if (!readSensorRegister(address, 0x0F, chipId)) return false;
        return chipId == 0x2C;
    }

    bool init(uint8_t address) override {
        _address = address;
        return writeRegister(address, 0x00, 0xA0);
    }

    std::vector<Metric> read() override {
        std::vector<Metric> out;
        float raw = readValue(_address);
        out.push_back({"my_value", raw, "unit"});
        return out;
    }

    std::vector<MetricDef> metrics() const override {
        return {{"my_value", "My Value", "unit"}};
    }

    uint32_t readInterval() const override { return 5000; }

    SensorModule* clone() const override { return new MySensorModule(); }
};

REGISTER_SENSOR(MySensorModule)
