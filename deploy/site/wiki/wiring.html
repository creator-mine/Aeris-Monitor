Подключение датчиков

Распиновка всех датчиков и свободные пины плат.

Общая схема: четыре провода

Все датчики общаются по I²C и подключаются четырьмя проводами.

Плата SDA SCL Питание шины
ESP32-C3, контроллер GPIO6 GPIO7 3,3 В
ESP32-C6, контроллер или модуль GPIO6 GPIO7 3,3 В
ESP32-S3 N16R8, контроллер GPIO8 GPIO9 3,3 В
🔌

Питание датчиков — 3,3 В, земля общая.

Подтяжки уже есть на модулях; дополнительные не нужны.

✅

Минимальный набор — BME680 и четыре провода.

Каждый датчик по отдельности

BME680 — температура, влажность, давление, газ

Вывод модуля Куда Примечание
VIN / VCC 3V3 Только 3,3 В
GND GND Общая земля
SDA GPIO6 (C3, C6) / GPIO8 (S3) Линия данных
SCL GPIO7 (C3, C6) / GPIO9 (S3) Линия тактирования
CSB 3V3 Высокий уровень = I²C
SDO GND / 3V3 Выбор адреса
  • Прошивка проверяет chip ID 0x61.
  • gas_resistance — не индекс качества воздуха.
  • Датчик греется — не ставьте над платой.
⚠️

В 1.3.2 адреса 0x76/0x77 не сканировались; исправлено в 1.3.3.

🔎

С 1.3.11 chip ID 0x61; есть диагностика шины по USB.

⚠️

GPIO5 — это UART TX и strapping; I²C только на 6/7.

BMP280 — температура и давление

Вывод модуля Куда Примечание
VIN / VCC 3V3 Только 3,3 В
GND GND Общая земля
SDA GPIO6 (C3, C6) / GPIO8 (S3) Линия данных
SCL GPIO7 (C3, C6) / GPIO9 (S3) Линия тактирования
CSB 3V3 Высокий уровень = I²C
SDO GND / 3V3 Выбор адреса
  • BMP280 точнее по давлению, но без влажности и газа.
  • Прошивка проверяет chip ID 0x58.

BH1750 — освещённость

Вывод модуля Куда Примечание
VIN / VCC 3V3 Только 3,3 В
GND GND Общая земля
SDA GPIO6 (C3, C6) / GPIO8 (S3) Линия данных
SCL GPIO7 (C3, C6) / GPIO9 (S3) Линия тактирования
ADDR GND / 3V3 Выбор адреса
  • Драйвер сам включает режим измерения.
  • Окно датчика должно смотреть на свет.

SCD30 — CO₂, температура, влажность

Вывод модуля Куда Примечание
VIN / VCC 3V3 или 5V 3,3–5 В
GND GND Общая земля
SDA GPIO6 (C3, C6) / GPIO8 (S3) Линия данных, 3,3 В
SCL GPIO7 (C3, C6) / GPIO9 (S3) Линия тактирования, 3,3 В
SEL GND Режим I²C
  • Адрес 0x61 фиксированный.
  • Первое значение — примерно через 15 секунд.
  • Автокалибровка рассчитана на свежий воздух.
  • Держите SCD30 вдали от источников тепла.

INA219 — напряжение, ток, мощность

Вывод модуля Куда Примечание
VIN / VCC 3V3 или 5V Питание логики
GND GND Общая земля
SDA GPIO6 (C3, C6) / GPIO8 (S3) Линия данных
SCL GPIO7 (C3, C6) / GPIO9 (S3) Линия тактирования
VIN+ Плюс источника Вход шунта
VIN− Плюс нагрузки Выход шунта
  • Шунт включается последовательно с нагрузкой.
  • Земля источника и нагрузки — общая.
  • Калибровка 32 В / 2 А.
  • Адрес 0x40, A0/A1 — низкий уровень.

Если адреса совпадают: TCA9548A

Два одинаковых датчика разводятся только мультиплексором.

Вывод TCA9548A Куда
VIN / VCC 3V3
GND GND
SDA / SCL GPIO6 / GPIO7 или GPIO8 / GPIO9
SD0 / SC0 … SD7 / SC7 SDA / SCL датчика
A0 / A1 / A2 Адрес 0x70–0x77
⚠️

Мультиплексор нужно включить в конфигурации.

Идентификаторы получают суффикс канала.

Проверка подключения

  1. Проверьте питание и землю

    Питание — 3,3 В, земля общая.

  2. Serial на 115200

    В логе будет строка о найденном датчике.

  3. Откройте API

    Модули — /api/v1/modules, значения — /api/v1/sensors.

  4. Если датчик не найден

    Проверьте адрес, питание, землю и CSB.
