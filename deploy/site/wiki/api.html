Параметр По умолчанию Смысл

История через MQTT

История доступна и по MQTT.

{
  "type": "command",
  "command": "history",
  "request_id": "h1795528584000",
  "sensor": "iaq",
  "since": 1795440000000,
  "limit": 500
}

. Один запрос отдаёт не больше 500 точек." data-en-html="The reply arrives on iot/<id>/sensors/history in chunks of up to 1.2 KB. Each has request_id, sensor, chunk, last and points. The final chunk has last: true and may contain an empty array. If the card is not mounted, error: "no_card" is included. One request returns at most 500 points.">Ответ приходит чанками.

С 0.4.3 сервер ждёт подтверждения платы.

Тело запроса регистрации

POST /api/v1/devices/register
Authorization: Basic base64(MQTT_DEVICE_USER:<пароль>)
Content-Type: application/json

{
  "id": "esp32c3_001",
  "name": "Main Controller",
  "type": "esp32c3",
  "ip": "192.168.1.50",
  "port": 80,
  "sensors": ["temperature", "humidity", "co2"]
}

Обязательны только идентификатор и адрес.

Тело запроса аварии

POST /api/v1/alerts
{
  "device_id": "esp32c3_001",
  "sensor_type": "temperature",
  "type": "above",
  "threshold": 27.5
}

Тело запроса правила

POST /api/v1/rules
{
  "name": "Уведомить о жаре",
  "device_id": "esp32c3_001",
  "trigger": "threshold_above",
  "sensor_type": "temperature",
  "threshold": 27.5,
  "action": "notify",
  "cooldown_seconds": 300
}

Топики MQTT

Топик строится из префикса и идентификатора.

Топик Направление Содержимое
iot/<id>/sensors/<ключ> устройство → подписчик Одно значение
iot/<id>/status устройство → подписчик Состояние и sd
iot/<id>/relay устройство → подписчик Состояние реле
iot/<id>/wifi/result устройство → сервер Результат переключения
iot/<id>/commands подписчик → устройство Команда устройству 
iot/esp32c3_001/sensors/temperature
{
  "device_id": "esp32c3_001",
  "sensor": "temperature",
  "timestamp": 1735689600000,
  "value": 21.40,
  "unit": "C"
}

Публикация только при изменении.

🚦

До синхронизации времени метки неверны.

метка_времени,ключ_метрики,значение,единица

Готовые примеры

Показать текущую температуру

curl -s http://192.168.1.50/api/v1/sensors \
  | grep -o '"temperature":[0-9.]*'

Подписаться на поток значений

mosquitto_sub -h spe4naz.online -p 1883 \
  -t 'iot/+/sensors/temperature' -v
