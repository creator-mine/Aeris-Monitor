Мост и хранилище включаются опционально.

Топики и форматы MQTT

Топик Что публикуется Кто пишет
iot/<deviceId>/sensors/<key> Показание датчика Контроллер
iot/<deviceId>/status Жизненные показатели устройства Контроллер
iot/<deviceId>/cmd Команда устройству Сервер

Показание датчика

{
  "device_id": "esp32c3_001",
  "sensor": "bmp280_temperature",
  "timestamp": 1727985000000,
  "value": 23.45,
  "unit": "degC"
}

timestamp в миллисекундах UTC, value — число.

Команда устройству

iot/esp32c3_001/cmd> {"cmd":"relay","state":1}

Короткая строка, которую понимает прошивка.

Хранилище: JSONL и роллапы

Каждая точка — строка в JSONL.

data/ingest/
├── raw/
│   └── esp32c3_001/
│       └── bmp280_temperature/
│           ├── 2026-10-07T14.jsonl   {"t":1727984700000,"v":23.41,"u":"degC"}
│           ├── 2026-10-07T15.jsonl   {"t":1727988300000,"v":23.52,"u":"degC"}
│           └── ...
└── rollup/
    └── esp32c3_001/
        ├── bmp280_temperature.jsonl  {"h":"2026-10-07T14","count":60,"min":23.1,"max":24.0,
        │                              "sum":1395.2,"avg":23.25,"first_t":...,"last_t":...}
        └── temperature.jsonl         ...

Роллап — статистика закрытого часа.

Синхронная допись, кэш последних значений.

Живой поток: SSE /api/v1/stream

Метрики сайту отдаёт SSE.

event: hello      data: {"version":"0.4.0","telemetry":{"esp32c3_001":{"temp":{"t":...}}}}
event: metric     data: {"deviceId":"esp32c3_001","sensor":"temp","t":...,"v":23.45,"u":"degC"}
event: status     data: {"deviceId":"esp32c3_001","status":"online","rssi":-61}
event: rule       data: {"rule":{...},"action":"mqtt_command","topic":"iot/esp32c3_001/cmd"}
event: cmd        data: {"deviceId":"esp32c3_001","command":"relay:on","ts":...}

hello со снимком, потом только живые события.

🔌

SSE — публичный эндпоинт.

История: /api/v1/sensors

Метод и путь Что возвращает
GET /api/v1/sensors/latest Последние значения
GET /api/v1/sensors/<deviceId>/<sensor>/history Временной ряд 
GET /api/v1/sensors/esp32c3_001/temp/history?from=1727982000000&to=1728014400000&points=200

Движок правил

Правила оцениваются и на сервере.

Триггер Когда срабатывает
threshold_above / threshold_below Значение пересекает порог
online / offline Статус устройства
no_data Тишина устройства

Команда или уведомление, кулдаун по умолчанию.

Ручная команда через API.

Настройка

Переменная По умолчанию Что задаёт
MQTT_ENABLED 0 Включает MQTT-мост
MQTT_HOST / MQTT_PORT 127.0.0.1 / 1883 Адрес брокера
MQTT_USER / MQTT_PASSWORD — Учётные данные брокера
MQTT_TOPIC iot/+/# Фильтр подписки
INGEST_DIR data/ingest Директория хранилища
INGEST_FLUSH_SECONDS 60 Частота сброса
