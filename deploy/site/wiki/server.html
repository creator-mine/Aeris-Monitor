nginx и маршрутизация

Весь публичный трафик собирает nginx.

Путь Куда попадает запрос
/ Главная страница сайта
/panel/ Веб-панель управления
/app/ Собранное веб-приложение
/fw/ Каталог прошивок
/api/v1/ Прокси на сигнальный сервер

Сервер в Docker-сети, наружу не публикуется.

Развёртывание с нуля

Стек запускается в Docker.

Подготовьте хост

sudo apt update
sudo apt install -y docker.io docker-compose-plugin nginx certbot
sudo systemctl enable --now docker nginx

Настройте окружение

cd /opt/iot/deploy/docker
cp .env.example .env
# заполнить NGINX_DOMAIN, PANEL_PASSWORD, MQTT_*
docker compose up -d --build

Статика — в runtime/site.

Подключите host nginx

sudo cp /opt/iot/deploy/iot-site.conf /etc/nginx/sites-available/spe4naz.conf
sudo ln -sf /etc/nginx/sites-available/spe4naz.conf /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

web слушает только 127.0.0.1:8080.

Выпустите сертификат

sudo mkdir -p /var/www/certbot
sudo certbot certonly --webroot -w /var/www/certbot -d spe4naz.online
sudo systemctl reload nginx

Продление — таймером certbot.

Проверьте

curl -s https://spe4naz.online/api/v1/health
curl -s -o /dev/null -w '%{http_code}
' https://spe4naz.online/panel/
curl -s -o /dev/null -w '%{http_code}
' https://spe4naz.online/app/

Резервное копирование

Сохранять нужно реестр, каталог прошивок и метрики.

# реестр, аварии, правила, метрики и сертификаты
sudo /opt/iot/deploy/docker/backup.sh

# архив: /var/backups/iot/iot-YYYY-MM-DD_HHMMSS.tar.gz
🔁

Восстановление сводится к распаковке на место.

Безопасность

  • Учётные данные — в файле окружения, не в репозитории.
  • Пароли MQTT и API обязательны.
  • Для сайта — отдельная учётная запись только на чтение.
  • Сертификат продлевается автоматически.
  • Панель закрыта паролем приложения.
  • Пароли не зашиты в приложение.
