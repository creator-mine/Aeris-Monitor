Графики и статистика

Период выбирается из готового набора.

  • Минимум и максимум показывают границы.
  • Среднее показывает типичное значение.
  • Пробелы не заполняются.

Аварии и пороги

Порог задаётся на пару «устройство + тип датчика».

Условие Типичный сценарий
above Температура выше нормы
below Влажность упала
equals Датчик молчит

Аварии хранятся на сервере.

Smart rules

Проверка выполняется на стороне приложения.

Поле Значения Смысл
trigger threshold_above
threshold_below
online
offline
no_data		 Что считается поводом
action notify
mqtt_command
device_command		 Действие при срабатывании
threshold число Порог
cooldown_seconds 0 … 604800 Пауза перед повтором
enabled true / false Выключено правило
🔁

Без паузы правило будет срабатывать слишком часто.
