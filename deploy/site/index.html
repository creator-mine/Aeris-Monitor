Архитектура

Масштабируемая модульная конструкция: от одного датчика до десятков комнат.

🧠 Главный контроллерESP32-C3

  • Собирает данные с сенсорных модулей по UART
  • Публикует метрики в MQTT брокер
  • Сохраняет историю на microSD (CSV)
  • Веб-API: /api/v1/sensors, история, команды
  • WebSocket — live-поток данных

🌡️ Сенсорные модулиESP32-C6

  • BME680 — температура, влажность, давление, IAQ
  • BH1750 — освещённость
  • Регистрация и heartbeat по UART-протоколу
  • Автоопределение новых модулей (plug & play)

☁️ Серверная частьNode.js

  • Сигнальный сервер — реестр устройств
  • Mosquitto (MQTT) — транспортировка данных
  • Автономен: регистрирует и раздаёт ip:port
  • Сертификат Let's Encrypt — защищённый HTTPS

📱 КлиентFlutter

  • Дашборд устройств в реальном времени
  • Графики и статистика за 24ч – 30д
  • Настройка аварий по порогам
  • Direct connection к устройству + MQTT

Модульность

Добавляйте сенсорные модули без перепрошивки — система сама их обнаружит по I²C/UART и зарегистрирует.

📡

Несколько транспортов

Данные идут по MQTT, WebSocket и REST одновременно. Приложение выбирает оптимальный канал.

💾

Сохранность данных

История пишется на SD-карту при каждом чтении. Даже при пропаже сети данные не теряются.

🔔

Аварии

Пороговые уведомления: температура выше нормы, влажность упала — приложение сразу покажет проблему.

📊

Графики

Режимы 1ч / 6ч / 24ч / 7д / 30д с минимальными, средними и максимальными значениями.

🔧

Команды re-scan, чтение сенсоров и перезагрузка устройства — прямо из мобильного приложения.

Инструкция

Сборка и подключение

Как прошить прошивку, настроить Wi-Fi и соединить модули между собой.

1Прошивка контроллеров

Код лежит в репозитории проекта, папка firmware/. Для каждого контроллера своя прошивка:

  • main_controller — главный контроллер на ESP32-C3 / C6 / S3 (Wi-Fi, MQTT, WebSocket, SD-карта, I²C-датчики)
  • sensor_module — сенсорный модуль на ESP32-C6 (читает датчики и шлёт их по UART на контроллер)

Среда сборки — PlatformIO. Из командной строки:

cd firmware/main_controller pio run -e esp32-c3 # сборка (C3) pio run -e esp32-c6 # сборка (C6-контроллер) pio run -t upload --upload-port COM5 # прошивка на плату cd firmware/sensor_module pio run -e esp32-c6 # сборка pio run -t upload --upload-port COM6 # прошивка на плату

Или через мобильное/десктопное приложение: раздел «Прошивка» → выбрать папку, устройство, COM-порт (кнопка «Определить чип» покажет фактический ESP32-C3/C6) → «Собрать» → «Загрузить».

2Первое включение и настройка Wi-Fi

При первом старте главный контроллер поднимает точку доступа Aeris-Setup-XXXX без пароля.

  • Подключитесь к сети Aeris-Setup-XXXX
  • Откройте в браузере http://192.168.4.1
  • Укажите SSID и пароль вашей Wi-Fi сети и сохраните
  • Контроллер перезагрузится и подключится к вашему роутеру, данные появятся в приложении

Если нужно переподключить к другой сети — отправьте устройству команду переконфигурации через приложение (Wi-Fi → «Сброс Wi-Fi»), оно снова вернётся в режим точки доступа.

3Соединение модулей: UART

Сенсорный модуль (ESP32-C6) передаёт данные главному контроллеру (ESP32-C3) по UART 115200 бод. Пин TX каждого контроллера соединяется с RX другого (перекрёстно):

Главный контроллер · ESP32-C3Сенсорный модуль · ESP32-C6
GPIO5 (TX, Serial1)→GPIO4 (RX, Serial1)
GPIO4 (RX, Serial1)←GPIO5 (TX, Serial1)
GND—GND
5V / VIN—5V / VIN
  • TX → RX подключаются перекрёстно: C3.GPIO5 → C6.GPIO4 и C6.GPIO5 → C3.GPIO4; земля общая
  • Питание модулей — от USB или общего блока 5 В
  • Датчики на одной плате могут расширяться — см. шаг 4

4Подключение датчиков: I²C

Сенсоры BME680 (температура, влажность, давление, качество воздуха) и BH1750 (освещённость) подключаются к шине I²C: SDA, SCL, питание 3.3V и общий GND. Ниже раскладка отдельно для каждой платы.

C3 работает и без сенсорного модуля C6: датчики на его собственной шине I²C, данные публикуются по Wi-Fi/MQTT, история — на SD-карту (CS — GPIO10).

C6 сам Wi-Fi не использует — он передаёт метрики по UART главному контроллеру (шаг 3). Состояние показывает светодиод на GPIO8 (мигает при активной передаче).

  • Частота шины — 100 кГц; адреса: BME680 — 0x76, BH1750 — 0x23
  • Несколько датчиков подключаются параллельно (SDA→SDA, SCL→SCL); подтяжки обычно уже на модулях
  • Прошивка автосканирует шину при старте (plug & play) и публикует найденные датчики

  • Прошивка вызывает SD.begin(SD_CS) — из кода задан только пин CS (GPIO10), линии данных берутся со стандартной SPI-шины платы
  • Карту форматируйте в FAT16/FAT32 — прошивка пишет историю показаний логами в CSV

9Диагностика неисправностей

Плата не отображается в списке COM-портов
  • Используйте USB-кабель с передачей данных, а не только питания
  • Установлены ли драйверы USB-моста: CH340 / CP210x / нативный USB (на Windows обычно ставятся автоматически)
  • Нажмите «Обновить список портов» в приложении и проверьте, что выбрана актуальная среда (esp32-c3 или esp32-c6)
  • На некоторых платах порт появляется только при удержании BOOT (режим загрузчика)
«Определить чип» не возвращает результат
  • По умолчанию esptool сам переводит плату в download-режим (DTR/RTS) — это работает на обычных devkit-ках
  • На самодельных платах без линий RTS/DTR задержите кнопку BOOT на время опроса (до «Chip is …»)
  • Убедитесь, что выбран именно тот порт, к которому подключена плата, и закройте другие программы, занимающие этот порт
Ошибка при прошивке: несовпадение чипа (chip mismatch)
  • Выбрана не та среда: код для ESP32-C3 пытаетесь загрузить на C6 или наоборот
  • Результат «Определить чип» автоматически сверяет фактический чип с выбранным устройством — добейтесь зелёного совпадения перед загрузкой
  • Проверьте, что порт соответствует нужной плате, если подключено несколько
Датчик не найден на шине I²C
  • Перепутаны SDA (GPIO6) и SCL (GPIO7)
  • Датчику не хватает питания: корректные адреса — BME680 0x76, BH1750 0x23
  • Нет общего GND между датчиком и платой, или провод длиннее ~20 см без подтяжки
  • После подключения перезапустите плату — сканирование шины идёт при старте
Данные не публикуются в приложение (нет MQTT)
  • Wi-Fi не настроен: при первом старте будет точка Aeris-Setup-XXXX — пройдите шаг 2
  • Проверьте и повторите настройку Wi-Fi командой «Сброс Wi-Fi» из приложения
  • Убедитесь, что сервер доступен: статус-индикатор на странице spe4naz.online
Данных от сенсорного модуля C6 нет
  • TX/RX подключены не перекрёстно: C3 GPIO5 → C6 GPIO4, C6 GPIO5 → C3 GPIO4
  • Скорость UART — строго 115200; проверьте общий GND между платами
  • Обе прошивки собраны: модуль — esp32-c6, контроллер — esp32-c3
  • Светодиод на GPIO8 модуля должен мигать при передаче кадров
